# Restaurant Ordering System

A menu-driven Python Restaurant Ordering System developed as a Day 5 mini-project using Object-Oriented Programming.

## Features

- View restaurant menu
- Search food items
- View unique food categories
- View items by category
- Add items to cart
- View shopping cart
- Remove items from cart
- Calculate subtotal, discount, tax, and final total
- Place orders
- Generate unique order IDs
- Save completed orders to a CSV file
- View order history
- Handle invalid user input gracefully

## OOP Concepts Used

- Classes and objects
- Constructors (`__init__`)
- Instance attributes
- Class attributes
- Instance methods
- Encapsulation
- Private attributes using `__`

## Python Concepts Used

- Variables
- Conditional statements
- `for` and `while` loops
- Functions
- Lists
- Tuples
- Sets
- Dictionaries
- Exception handling
- CSV file handling
- Docstrings
- Type hints

## Files

- `restaurant_ordering.py` - Main Python application
- `orders.csv` - Stores completed order records
